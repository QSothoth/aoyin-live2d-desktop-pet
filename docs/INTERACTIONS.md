# 交互与动画状态映射

| 触发 | hatch-pet 状态 | 行为 |
|---|---|---|
| 默认 | `idle` | 呼吸、眨眼、耳朵和尾巴轻动 |
| 向右拖动 | `running-right` | 面向右的交替步态 |
| 向左拖动 | `running-left` | 面向左的交替步态 |
| 单击 / 摸头 | `waving` | 克制挥手 |
| 双击 / 喂罐头 | `jumping` | 起跳回应 |
| 长时间无互动 | `failed` | 垂耳、收尾、蜷身小憩 |
| 需要用户回应 | `waiting` | 竖耳前倾、侧头倾听 |
| 陪伴工作 | `running` | 专注思考，不做物理奔跑 |
| 审阅 | `review` | 前倾审视、视线与手部微动 |

这些语义直接对应 `spritesheet.webp` 的 0–8 行。应用不通过缩放或扭曲静态图伪造动作。

## 0.2 自主行为层

| 行为 | 默认节奏 | 打断规则 |
|---|---:|---|
| 稀疏眨眼 | 7–16 秒 | 任意动作立即打断 |
| 安静自娱 | 45–110 秒 | 拖动、点击、菜单动作立即打断 |
| 擦眼镜 | 5–11 分钟 | 用户操作立即打断 |
| 自主散步 | 4–9 分钟 | 拖动或锁定位置立即打断 |
| 狼形态 | 15–30 分钟 | 用户操作立即打断 |
| 主动短句 | 至少间隔 10 分钟 | 仅约 22% 的自主行为伴随台词 |

拖放结束后，主进程根据当前显示器的 `workArea` 计算左、右、上、下边缘距离；34 px 内触发 `edge-peek`。目前不枚举第三方应用窗口，避免引入平台相关的窗口注入权限。
