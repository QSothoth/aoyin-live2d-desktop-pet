# 敖隐桌宠角色锁定规范

## 视觉身份

- Q 版二次元狼系少年，头身比约 1:2.4，紧凑全身轮廓。
- 深酒红色蓬松短发，发尾偏暗紫红；头顶一对同色狼耳，耳内浅粉白绒毛。
- 金棕色眼睛，细长黑色矩形眼镜；神情克制、略傲娇但亲近。
- 日常造型固定为暗红圆领毛衣、黑色项链与银色小吊坠、深灰宽松长裤、白灰运动鞋。
- 身后固定一条巨大蓬松酒红狼尾，尾尖更深；不可改成狐狸、猫或小型尾巴。
- 不得新增文字、Logo、武器、悬浮特效、地面阴影或背景场景。

## 性格与动作语言

- 平时安静陪伴，呼吸、眨眼、耳朵轻动、尾巴缓慢摆动。
- 打招呼时克制地挥手；开心时尾巴更活跃。
- 等待用户时微微前倾、耳朵竖起；工作时专注思考，不做跑步动作。
- 失败时耳朵垂下、尾巴收拢，保持可爱而不夸张。
- 拖动时才使用左右奔跑姿态；跳跃只靠身体位移，不添加尘土或落地特效。

## 一致性红线

- 每一帧必须保持同一张脸、发型、眼镜、服装、鞋、项链、耳朵与尾巴设计。
- 不允许换装、改色、丢失眼镜、缩小尾巴、兽化四足或成人写实比例。
- 最终显示尺寸约 220–320 px，细节必须在小尺寸下清晰。
